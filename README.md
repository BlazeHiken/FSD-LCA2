# FSDLCA2 — Web Development Lab Assignments

This repository contains six web development lab assignments covering JavaScript, DOM manipulation, form validation, and React fundamentals.

## Assignments

| Assignment | Topic                                 | Technologies                      |
| ---------- | ------------------------------------- | --------------------------------- |
| 1          | JavaScript Calculator using Functions | HTML, CSS, JavaScript             |
| 2          | DOM-based To-Do List                  | HTML, CSS, JavaScript, DOM        |
| 3          | JavaScript Form Validation            | HTML, CSS, JavaScript             |
| 4          | React Profile Card using Props        | React, JSX, CSS, Vite             |
| 5          | Controlled React Form                 | React, JSX, `useState`, CSS, Vite |
| 6          | React Counter App using `useState`    | React, JSX, `useState`, CSS, Vite |

## Assignment Details

### Assignment 1 — JavaScript Calculator

A calculator that performs:

- Addition
- Subtraction
- Multiplication
- Division

JavaScript functions are used for the arithmetic operations, with a `switch` statement used to select the operation.

### Assignment 2 — DOM-based To-Do List

An interactive to-do list demonstrating DOM manipulation.

Features:

- Add tasks dynamically
- Mark tasks as completed
- Delete tasks dynamically

### Assignment 3 — JavaScript Form Validation

A registration form with JavaScript-based validation for:

- Name
- Email
- Phone number
- Password

Appropriate error messages are displayed when invalid input is provided.

### Assignment 4 — React Profile Card using Props

A React profile card component that receives the following information through props:

- Name
- Image URL
- Description

This assignment demonstrates React components, JSX, and props.

### Assignment 5 — Controlled React Form

A controlled React form that accepts user input and displays the entered information in real time.

This assignment demonstrates:

- `useState`
- Controlled inputs
- `onChange` event handling
- State-driven rendering

### Assignment 6 — React Counter App

A React counter application with:

- Increment
- Decrement
- Reset

The application uses React's `useState` hook to manage the counter value.
